# Vista Bay Website

This project is a luxury real-estate landing page built with static HTML and CSS.

## Files
- [index.html](index.html) — landing redirect for GitHub Pages
- [files/vista-bay-website.html](files/vista-bay-website.html) — main website
- [RAM.mp4](RAM.mp4) and [RAM2.mp4](RAM2.mp4) — video assets

## GitHub upload

1. Create a GitHub repository.
2. Push this folder to the repository.
3. Enable GitHub Pages from the repository settings.
4. Select the root branch and root folder.

## Example commands

```bash
git init
git add .
git commit -m "Initial website upload"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
git push -u origin main
```

After pushing, GitHub Pages will serve the site from `index.html`.
